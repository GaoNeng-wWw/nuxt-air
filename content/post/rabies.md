# 狂犬病

::tags
::

狂犬病是一种有狂犬病病毒引起的人畜共患疾病, 可在恒温动物身上造成严重的脑炎. 对于未接种疫苗的患者, 神经症状出现时几乎100%死亡.

## 狂犬病毒

::pic{src="/images/rabies.svg" title="狂犬病病毒示意图"}
::

狂犬病毒属于弹状病毒科, 狂犬病毒属. 核衣壳呈螺旋对称, 内含有单股负链RNA. 狂犬病毒主要通过受感染动物的唾液传播, 少数由抓伤传播, 少有因器官移植而导致的狂犬病. 狂犬病毒**不会**突破完整的皮肤.

### 基因组

狂犬病毒是单股负链RNA. 狂犬病毒包含五种蛋白, 糖蛋白(G), 核蛋白(N), 双聚酶(L), 磷蛋白(P), 基质(M).

| 蛋白名称 | 主要功能描述                                                                                                 |
|----------|-----------------------------------------------------------------------------------------------------------|
| 核蛋白   | 可溶性N-P复合物专门包裹基因组RNA, 蛋白质N像珍珠项链一样保护基因组. 包裹的基因组RNA被称为核衣壳（NC）, 并作为病毒转录和复制的模板. |
| 糖蛋白   | 将病毒附着在宿主细胞受体上, 利用不同的宿主蛋白诱导病毒颗粒的内吞作用, 决定病毒的致病性和组织嗜性.                            |
| 基质     | 在病毒组装、形态发生、包膜病毒粒子出芽以及调节RNA合成并深刻影响复制和转录产物的平衡[[@mbs:/content/journal/jgv/10.1099/vir.0.19128-0]].                            |
| 双聚酶   | 催化病毒mRNA的转录、封盖和多聚腺苷酸化                                                        |
| 磷蛋白   | 在病毒转录和复制中起作用的非催化聚合酶辅因子和调节蛋白. 将RNA聚合酶L稳定在N-RNA模板上, 并结合可溶性蛋白N, 防止其包裹非基因组RNA. |

### 感染

狂犬病在感染初期时并不会和普通病毒一样迅速的引起发热与严重的炎症反应. 当伤口或组织粘膜接触到病毒后, 病毒首先会侵染伤口附近的骨骼肌, 而后会与肌肉细胞表面受体结合, 结合位点主要取决于G蛋白, 通常是烟碱乙酰胆碱受体[[@10.1126/science.7053569]].

RABV具有高度的神经趋向性, G蛋白的分子结构与`神经肌肉接头`特有的受体高度适配. 神经肌肉接头是运动神经元末梢与骨骼肌纤维接触的特殊部位. 这里为了保证神经信号的高效传递, 演化出了极高浓度的特异性蛋白质, 这些蛋白质被病毒“借用”成了入侵的受体.

病毒进入到神经元后, P蛋白将会与LC8二聚体结合将病毒RNP挂载到微管轨道上, 动力蛋白利用水解ATP产生的能量向胞体移动,从而病毒完成从伤口到中枢神经的转运.

在该阶段, 患者表现不一, 50%-80%的患者会感觉到伤口处出现异常例如: 蚁走感、瘙痒、刺痛等

### 死亡

病毒最终高度集中在脑干（延髓、桥脑），这里是呼吸和心跳的中枢。病毒诱发的神经元功能障碍导致恐水症（吞咽肌痉挛）、呼吸节律紊乱和心律失常。大多数患者死于呼吸衰竭或循环系统崩溃。

### 免疫

G蛋白是狂犬病病毒中最主要的抗原,利用不同的宿主蛋白诱导病毒颗粒的内吞作用, 决定病毒的致病性和组织嗜性. 但RABV并不入血, 只会通过动力蛋白沿微管逆行运输, 这就使得免疫系统难以与完整的病毒颗粒解除, 导致抗原呈递几乎无法完成.

病毒进入到中枢神经系统后并不会破坏血脑屏障, 即使在感染后期T细胞产生了一定数量的抗体也无法透过血脑屏障中和RABV.

## 治疗

RABV的治疗方案主要分为暴露后补救(PEP)与临床干预.

### PEP

狂犬病毒的致死性在于其进入中枢神经系统后的不可逆性. PEP 的核心逻辑是在病毒通过轴突逆行运输到达脊髓之前, 通过人工免疫手段将其阻断. 通过人工注射疫苗诱导机体对G蛋白产生特异性抗体, 在病毒进入中枢神经前将其中和.

对于三级暴露, 还会在伤口处浸润狂犬病免疫球蛋白, 剩余RIG则会肌肉注射在远离疫苗注射部位的肌肉处, 用于填补产生抗体前的真空期.

### 临床干预

临床干预主要是两种思路, 密尔沃基疗法与中枢给药. 不过, 目前的临床结论是狂犬病发病后尚无确证有效的救治手段.

密尔沃基疗法的核心思路在于, 既然病毒没有产生结构性的伤害, 通过抑制大脑活动, 减少氧耗和神经毒性积累, 为机体免疫系统产生抗体争取时间. 但是这种治疗方案具备争议性, 除了最初的病例被成功救活外球多次重复该疗法均告失败.

中枢给药, 通过鞘内注射直接向脑脊液中投送抗体弥补抗体无法穿透血脑屏障的问题.
